Политика конфиденциальности

Приложение «Личный ИИ-агент Егора». Действует с 23 ноября 2026 года.

Кто пользуется приложением

Только его владелец, Егор Кононов. Приложение работает с его собственным аккаунтом Google и не принимает других пользователей.

Какие данные используются

События календарей Google владельца: название, время, длительность. Доступ запрашивается только к событиям календаря.

Зачем

Чтобы личный ИИ-помощник мог по просьбе владельца создавать, переносить и удалять события в его календаре.

Где хранятся данные

Ключ доступа хранится на личном сервере владельца. Данные календаря не копируются в сторонние хранилища, не продаются и не передаются третьим лицам. Для рекламы и обучения моделей они не используются.

Использование данных, полученных через Google API, соответствует Google API Services User Data Policy, включая требования Limited Use.

Как отозвать доступ

В настройках аккаунта Google: myaccount.google.com/connections → приложение → «Удалить доступ». После этого ключ на сервере перестаёт работать.

Связь

egor@kononov.me

This is a private app used only by its owner, Egor Kononov, with his own Google account. It accesses Google Calendar events solely to create, move and delete events at the owner's request. The access token is stored on the owner's personal server. Calendar data is not shared with third parties, sold, or used for advertising or model training. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/connections. Contact: egor@kononov.me.
